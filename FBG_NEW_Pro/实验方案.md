# 长距离四芯光纤光栅3D形状传感实验方案

**研究者**：计算机科学与技术（学硕）  
**目标期刊**：四区（冲三区）  
**核心方向**：算法改进——用深度学习重建替代传统逐段积分，解决长距离累积误差发散问题

---

## 一、研究背景与创新点

### 核心问题
传统形状重建方法（Frenet-Serret / Bishop 逐段积分）存在**误差累积发散**问题：
- 每一段的曲率估计误差会往后传
- 弧长越长，末端误差越大（已在仿真中验证：2m光纤Frenet端点误差约800mm）

**误差不是均匀累积的，而是在"拐点"处集中爆发**（这是比"累积"更精确的病因定位）：
- 拐点 = 曲率过零、弯曲方向翻转处（如S形中段）
- 三重原因叠加：① Frenet在κ→0处数学奇异（挠率τ→∞）；
  ② 拐点处弯曲信号最弱、信噪比最低；③ 方向角φ在κ≈0时剧烈抖动
- **长距离 = 拐点多 = 误差被反复注入放大**，这正是短距离论文（导管/内窥镜）
  碰不到、因而没研究的缝隙

### 创新点（论文卖点）
> 将形状重建从"逐段积分"转化为"序列到序列深度学习"，通过双向编码器实现全局去噪，并引入**可微物理积分层**与**端点累积误差惩罚损失**，在长距离场景下显著抑制误差发散。

具体包含：
1. **双向编码器（BiLSTM/Transformer）**：每个点同时看前后所有测量值，实现全局去噪
   （传统积分只能"看过去"，单向传播；双向网络能用全局信息在拐点处"接力"去噪）
2. **可微 Bishop 积分层**：物理公式写成可反传梯度的层，保证输出曲线物理合理
3. **端点累积误差惩罚 Loss**：直接惩罚末端误差，让网络学会"预补偿"累积偏差
4. **直角曲率空间 (k1,k2) 表示**：用 (k1,k2) 代替极坐标 (κ,φ)，平滑穿过零点，
   从表示层面根除拐点奇异（极坐标在κ=0处奇异、φ跳变，是Frenet爆炸的根源）
5. **不确定性加权**：网络在低曲率/低信噪比的拐点区域自动降低对本地测量的信任
6. **仿真预训练 + 真实数据微调**：解决 sim-to-real gap

## 三、实验方案步骤

### 第一阶段：仿真数据生成（第1~2周，纯代码，不需要设备）

**目标**：生成10万条 (Δλ, 3D坐标) 训练样本

**原理**：
- 物理正向模型完全已知，无需ANSYS
- 欧拉-伯努利梁公式：`ε = r × κ × cos(φ - φᵢ)`
- FBG公式：`Δλ = λ₀ × (1 - pₑ) × ε`，pₑ ≈ 0.22

**步骤**：
1. 用B样条随机生成光滑3D曲线
2. Bishop标架积分，计算各点曲率(k1, k2)
3. 套公式计算四芯各自的Δλ
4. 加入真实解调仪噪声（查说明书获取波长重复性指标，填入`config.py`的`NOISE_DLAMBDA`）
5. 循环10万次，存成`train.npz / val.npz / test.npz`

**运行命令**：
```bash
python3 data_generation.py    # 约14分钟（CPU）
```

---

### 第二阶段：模型设计与训练（第3~4周）

**模型架构**（物理嵌入式可微积分网络）：

```
Δλ (n×4)
   ↓
双向LSTM / Transformer（全局去噪）
   ↓
输出曲率估计 (k1, k2) (n×2)
   ↓
可微 Bishop 积分层（固定物理公式，无参数，梯度可反传）
   ↓
3D坐标 (n×3)
   ↓
端到端损失函数（含端点惩罚项）反传梯度
```

**损失函数**：
```
L = L_逐点误差 + 5.0 × L_端点误差 + 0.1 × L_平滑约束 + 0.5 × L_弧长一致性
```

**训练策略**：
- 仿真数据预训练（10万条）
- 加入域随机化（随机扰动光纤几何参数，增强鲁棒性）
- 推荐在 Google Colab（免费GPU）上训练，约10~20分钟

**运行命令**：
```bash
python3 train.py                      # LSTM（主推）
python3 train.py --model transformer  # Transformer（消融对比）
```

### 第三阶段A：标定实验（第5周，先做这个）

**目的**：测出你这根四芯光纤真实的"应变-波长"灵敏度系数，替换仿真里的理论值。

**做法（悬臂梁加载法）**：
1. 四芯光纤直直固定在金属梁上（一端固定，悬臂）；
2. 记录无载荷时各芯基准波长 λ₀；
3. 末端依次挂已知砝码（50g/100g/200g…），每个载荷对应已知应变（材料力学公式算）；
4. 记录每个载荷下各芯 Δλ；
5. 画 Δλ vs 应变 ε 直线，斜率即灵敏度系数 K_ε。

| 砝码(g) | 理论应变ε(με) | 芯1 Δλ | 芯2 Δλ | 芯3 Δλ | 芯4 Δλ |
|--------|--------------|--------|--------|--------|--------|
| 0 | 0 | 0 | 0 | 0 | 0 |
| 50 | … | … | … | … | … |
| 100 | … | … | … | … | … |

**产出**：把实测 K_ε 填进 `config.py`，让仿真数据更接近真实。

### 第三阶段B：真实实验验证（第5周，半天完成）

**目标**：用15~20组真实数据验证模型在真实环境下的精度

#### 材料准备
- PVC水管4种规格（五金店购买，总价约20元）：
  - DN15（外径约21mm）→ 大曲率
  - DN25（外径约33mm）→ 中曲率
  - DN40（外径约48mm）→ 小曲率
  - DN50（外径约60mm）→ 更小曲率
- 游标卡尺（实验室必有，测量精度0.02mm）

#### 真值计算
```
测量圆柱外径 D（游标卡尺）
曲率真值 κ = 2 / (D + d_fiber)    d_fiber ≈ 0.25mm 可忽略
形状真值：已知螺旋线（解析精确值）
```

#### 实验步骤
1. 用游标卡尺测量每根水管外径D，记录
2. 将四芯光纤沿水管缠绕3~5圈，固定
3. 连接解调仪，采集四芯波长数据（Δλ）
4. 每种水管采集3~5组，共15~20组数据
5. 存成与仿真数据相同格式的`.npz`文件

#### 真值的三种获取方式（按精度从高到低）

| 方式 | 适用 | 真值来源 | 关键提醒 |
|------|------|---------|---------|
| ① 圆柱缠绕 | 曲率/螺旋线 | κ=2/(D+d)，已知解析值 | 精度最高 |
| ② 坐标纸 | 平面S形（含拐点）| 读关键点坐标(±1mm) | 专测拐点 |
| ③ 尺子多点测高 | 任意弯曲 | 沿光纤每20cm量一次高度 | **不要只量末端！** |

> 方式③是你之前用的方法，改进点：沿光纤**多设几个测点**（每20cm一个），
> 才能验证整条曲线形状，而不只是末端一个点。重建结果的Z坐标与尺子高度对比。

#### 拐点专项实验（对应核心创新，必做）

把光纤弯成**S形或蛇形（含2~4个拐点）**，用坐标纸取真值，
重点对比传统方法和本文方法**在拐点附近的误差**。
产出图："误差 vs 距最近拐点的距离"——直接证明你定位并解决了拐点误差。

#### 可选：微调（强烈推荐，缩小sim-to-real gap）
```bash
python3 train.py --finetune real_data.npz   # 用5组真实数据微调，剩余15组测试
```

### 第四阶段：对比实验（第6~7周）

**对比方法**（相同数据，跑以下4种方法）：

| 方法 | 类型 | 说明 |
|------|------|------|
| Frenet-Serret 逐段积分 | 传统baseline | 经典方法，误差发散严重 |
| Bishop 标架逐段积分 | 改进baseline | 消除奇异点，仍有累积误差 |
| 普通双向LSTM（无端点Loss） | 消融对比 | 验证端点Loss的贡献 |
| **本文方法（含端点Loss+物理层）** | **提出方法** | 主要结论 |

**消融实验**（逐步去掉模块，看误差增量）：
- 去掉端点Loss → 误差增加多少？
- 去掉物理积分层（纯黑盒）→ 误差增加多少？
- 用Transformer替换LSTM → 精度变化？

**产出图表**：
- `error_vs_arclength.png`：误差随弧长增长曲线（**论文最重要的图**）
- `sample_reconstruction.png`：单条样本3D重建对比
- `metrics.csv`：各方法端点误差均值/标准差/RMSE

**运行命令**：
```bash
python3 evaluate.py
```

1. **替换真实噪声参数**  
   打开 `config.py`，把 `NOISE_DLAMBDA = 1.0e-3` 改成你解调仪说明书上的真实波长重复性指标（单位nm）

   Frenet/Bishop/网络三种方法必须跑同一批测试数据，不能各自用不同数据集
